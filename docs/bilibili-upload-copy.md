## PM 产品交互流程

### 标题

Northstar 实机演示｜从需求调研到 PRD 签核的完整 PM 流程

### 创作声明说明

本视频为 Northstar Desktop 的真实操作录屏。演示中的需求调研、PRD 草案和评审建议包含 AI 生成内容，由用户逐项确认、补充和签核。

### 简介

以家庭图片视频网站 media-harbor 为例，演示 Northstar Desktop 如何把一个产品想法推进到经 PM 签核的需求基线。

过程包含：提出想法与创建需求、需求调研、逐项确认与补充约束、生成和查看 PRD、处理评审问题，以及最终 PRD 签核。视频保留真实操作和等待过程，时长 29 分 41 秒。

## Dev 技术交互流程

### 标题

Northstar 实机演示｜从技术调研到 TD 评审与实现步骤确认

### 创作声明说明

本视频为 Northstar Desktop 的真实操作录屏。演示中的技术调研、TD 草案、评审建议和实现步骤包含 AI 生成内容，由用户与产品角色共同确认和修订。

### 简介

接续已由 PM 签核的需求，演示 Northstar Desktop 在 Dev 角色中的技术流程：从技术调研开始，生成技术设计文档 TD，组织评审，处理需求异议，再同步 TD、重新评审并确认实现步骤。

录像包含 PM 与 Dev 之间的需求异议收口，以及技术评审问题的批量修订。最后展示实现步骤确认，不代表代码开发已经完成。视频保留真实操作和重试过程，时长 1 小时 7 分 1 秒。
