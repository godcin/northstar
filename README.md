**Northstar｜对话驱动的 AI 研发协作平台**

通过自然语言对话，串联需求分析、技术设计、代码实现、测试验收与发布确认，让团队在统一工作流中推进软件交付。

- **多角色协作**：围绕 PM、Dev、QA 的职责组织任务、产物与交接，保持需求、实现和验收目标一致。
- **流程可控**：通过显式状态机、领域门禁与分级审批，确保关键操作满足权限和流程要求。
- **结果可验证**：结合结构化工具调用、执行校验与审计追踪，让操作有依据、结果有证据、过程可追溯。
- **能力可扩展**：支持模块化 Skill、MCP 工具接入与多模型适配，满足不同研发场景的需求。

**技术栈**：Python · FastAPI · Electron
