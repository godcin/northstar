# 03 · 回滚能力

恢复点让产品回到过去的某个时间点，而不是靠手动撤销。

## 随时回到之前的状态

在桌面端顶部点击「恢复点」，选择要回到的时间点，再按界面提示确认。恢复点目前只在桌面端提供。

## 恢复的内容

- 聊天、角色和待确认步骤一并恢复，可以继续操作。
- 代码、知识库和业务数据回到该时间点。
- 恢复前，当前的修改和旧聊天会先备份。
- 恢复会先停止当前任务。

## 只回滚需求分支

需求分支可以单独回滚：代码仓和知识仓的需求分支一起回到指定时间，main 分支和聊天数据保持不变。

回滚结果按仓库分别显示：已回滚、尚未回滚、无改动或结果未知。结果未确认时，可以核对结果后继续回滚。

## 恢复之后

恢复结果可以推送到远端；推送失败时可以重试。恢复点已经失效时，界面会提示刷新后重试。
